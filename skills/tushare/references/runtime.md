# Runtime configuration
Use doctor/setup to discover the installed Python and data root. External config/settings.json requires provider, token_file and sdk_url. Credentials are read only in memory; do not put them in strategy snapshots or chat. The official SDK entry is `from tushare_env.runtime import api; pro=api()` in the package's installed Python; pass api=pro to pro_bar. Query uses a bundled read-only allowlist; private compatible gateways require explicit user configuration, and their permissions are not official endpoint verification. MCP is an optional read-only bridge, discovered schemas can use symbol where the SDK uses ts_code. Configure its usage file externally. Tool discovery does not prove access. Output paths must be unused and immutable. CONFIG_REQUIRED and permission failures remain explicit.

## Initialize external settings
Run `tushare-env config init --token-file /path/to/token --sdk-url APPROVED_SERVICE_URL` after confirming the service endpoint with the user. Add `--usage-file /path/to/usage` when the read-only MCP bridge needs it. The command stores a credential-file path, never the token value, creates settings with owner-only permissions, and preserves existing settings. If settings already exist, inspect them privately and plan an explicit backed-up update. Verify with `tushare-env doctor --json`.
